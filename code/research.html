복부 CT의 AEC·체성분 landmark 지표를 이용한 고혈압·당뇨·만성콩팥병 분류

연구 진행 보고서 · JangHoon Chun · 모델 실험 앱: localhost:8501 (streamlit run code/app.py)

한 줄 요약
복부 CT에서 측정한 내장지방·피하지방·근육·노출선량(AEC) 값을 성별·나이·키·체중에 더해도, 고혈압·당뇨·만성콩팥병을 구분하는 정확도(AUC)는 유의하게 좋아지지 않았다. 내장지방은 병이 있는 군에서 확실히 많았지만(연관성), 그것이 진단 정확도 향상으로는 이어지지 않았다. 환자 수가 적어 "효과 없음"까지 단정하기는 어렵다.

초록

배경·목적 복부 CT의 내장지방(VAT)·피하지방(SAT)·근육(TAMA) 면적과 자동노출조절(AEC) 값이 성별·나이·키·체중 외에 고혈압(HTN)·당뇨(DM)·만성콩팥병(CKD) 분류에 얼마나 더 도움이 되는지 확인한다.

방법 두 병원의 단면 코호트(Gangnam 1,436명, Sinchon 1,129명)에서 정상군(세 질환 없음)과 질환 단독군을 비교했다. 후보 feature 333개(landmark 단면 값, 같은 위치 안의 지표 비, 위치 간 비)에서 Gangnam valid AUC만으로 로지스틱 forward selection을 했다. Gangnam은 train/valid/test = 70/10/20으로 나눴고, internal test와 Sinchon 외부검증은 평가에만 썼다. baseline과의 ΔAUC는 paired bootstrap 95% CI와 DeLong 검정(질환 3개 Holm 보정)으로 봤다.

결과 세 질환 모두 baseline 대비 AUC가 유의하게 오르지 않았다. internal test ΔAUC는 −0.046~+0.030이고 95% CI가 모두 0을 포함했다. external ΔAUC는 세 질환 모두 음수(−0.044~−0.008)였다. CI 폭이 HTN ±0.05, CKD ±0.1 정도여서 +0.03~0.05 수준의 향상은 배제하지 못한다. 전체 환자를 미보정으로 비교한 분석(3.3절)에서는 정상군과 질환군의 VAT 평균 차이가 가장 컸다.

결론 이 표본과 설계에서는 landmark 지표가 기본 정보 이상으로 분류 성능을 높인다는 근거를 얻지 못했다. 다만 양성 수가 적어 "효과가 없다"고 결론짓기는 어렵다. 특히 CKD 단독군(22명, 14명)은 해석이 어렵다.

1. 서론

  • 이미 찍은 CT에서 추가 비용이나 방사선 없이 만성질환 위험군을 가려낼 수 있는지 알아보려는 연구다(opportunistic screening). 다만 대상이 임상 적응증으로 CT를 찍은 환자라 일반 선별 인구와는 다르고, 현재 유병 상태를 분류하는 설계다.
  • VAT가 SAT보다 HTN·DM과 더 강하게 연관된다는 보고는 많다(부록). 하지만 landmark별 지표를 기본 정보에 더했을 때 예측 성능이 좋아지는지를 본 근거는 많지 않고, AEC를 질환 지표로 다룬 연구는 찾지 못했다.
  • 연구 질문: 기본 정보에 landmark별 체성분·AEC 지표를 더하면 HTN·DM·CKD 분류 AUC가 internal test와 external 모두에서 올라가는가. VAT 관련 지표가 가장 기여할 것으로 예상했다.
  • 이 연구는 사전 등록 없이 진행한 탐색적 연구다. 평가 방식은 hold-out에서 5-fold CV를 거쳐 7/1/2 hold-out으로 정리했고, 그 과정에서 이전 분석의 test·external 결과를 참고했다. 현재의 feature 정의(Tier1·Tier2), 선택 규칙(0.005 컷오프), 성공 기준도 이전 결과를 본 뒤에 정했으므로 external은 완전한 blind 검증이 아니다.

2.1 코호트와 품질 관리

  • Gangnam(내부 학습)과 Sinchon(외부검증)의 단면 코호트. 환자 1명당 CT 1건.
  • 포함: 체성분 곡선(VAT·SAT·TAMA), 임상 변수(성별·나이·키·체중), 질환 라벨(HTN·DM·CKD)이 모두 있는 환자.
  • 품질 관리(QC): 위에서 아래로 T10 → L1~L5 → S1 → 대퇴골두 → 치골 순으로 slice 번호가 커져야 하는데 그렇지 않거나, 간 상부가 치골보다 아래에 있는 환자는 landmark를 잘못 찾은 것으로 보고 제외했다(Gangnam 7명, Sinchon 16명). 최종 Gangnam 1,436명, Sinchon 1,129명.

2.2 환자 그룹핑

  • 정상군: HTN·DM·CKD가 모두 없는 환자. 진단 기록이 없다는 뜻이라 미진단 환자가 섞여 있을 수 있다.

2.3 데이터 분할과 평가 프로토콜

Gangnam을 train 70% / valid 10% / internal test 20%로 나눴다. valid는 feature 선택에만, internal test는 선택에 쓰지 않은 평가에만 썼다. Sinchon 전원은 train+valid로 다시 학습한 고정 모델을 한 번만 적용하는 external 검증에 썼다.

  • 환자 단위로 질환 비율을 유지(stratified)해 나눴고 seed는 111로 고정했다. PatientID 중복이 없음을 확인했다.
  • feature 선택에는 valid AUC만 썼고, 선택이 끝난 뒤 internal test·external 성능을 보고 feature나 모델을 바꾸지는 않았다. 다만 이 절차 자체가 이전 분석 결과를 본 뒤에 정해졌다는 점은 서론에 적은 대로다. 이전에 test·external p로 feature를 골랐을 때 개선이 유의하게 보이다가 valid 기반으로 바꾸자 사라졌다.

2.5 Feature 선택과 모델

333개 후보 중 어떤 feature를 모델에 넣을지는 아래 방식으로 정했다. 기준은 오직 Gangnam valid 데이터의 AUC다. internal test, external(Sinchon), p값, OR은 선택에 쓰지 않았다.

  1. 성별·나이·키·체중(baseline)만 넣은 로지스틱 회귀를 train으로 학습하고, valid AUC를 기준값으로 잡는다.
  2. 333개 후보를 하나씩 baseline에 더해서 valid AUC를 각각 계산한다.
  3. 가장 AUC가 높은 후보가 기준값보다 0.005 이상 올렸으면 추가하고, 그 AUC를 새 기준값으로 삼는다. 0.005 미만이면 선택을 끝낸다.
  4. 개수 제한 없이 2~3을 반복한다.

결과적으로 HTN 6개, DM 4개, CKD 3개가 선택됐다. 개수 상한을 두지 않고 다시 선택해도 같은 feature가 나왔다.

세부 조건은 다음과 같다. 평가 모델은 로지스틱 회귀(C=1)이고 train 중앙값으로 결측을 채운 뒤 train 기준으로 표준화한다. 질환마다 같은 split(seed 111)에서 따로 선택했다. 선택이 끝난 feature(표 3)는 그대로 고정해서 internal test와 external에 한 번만 적용했다.

2.6 통계 분석

  • AUC 차이(Δ)의 95% CI는 같은 환자를 쓰는 paired bootstrap(500회)으로, p는 DeLong 검정으로 구했다. AUC 외에 Brier score와 민감도·특이도·PPV·NPV를 함께 보고한다.
  • 다중비교는 HTN·DM·CKD 3개를 한 계열로 묶어 코호트별로 Holm 보정을 했다. 성공 기준은 internal과 external 모두 Δ>0이고 Holm p<0.05인 것이다. 후보 333개에서 고르는 다중성은 valid로만 선택하는 절차(2.3)로 다뤘다.
  • Odds ratio(+1SD당)는 각 코호트의 정상+질환 단독 전체에 로지스틱 회귀로 구했다.

3.3 질환군과 정상군의 landmark 평균 차이

이 절은 복합 질환자를 포함한 전체 환자를 대상으로 해서 정상 vs 단독 설계와 대상이 다르다.

질환이 있는 군은 정상군보다 내장지방(VAT)이 눈에 띄게 많았고, 이는 근육·피하지방·AEC보다 뚜렷했다. 나이·성별·BMI를 보정한 뒤 두 코호트에서 모두 일관된 것은 HTN의 VAT뿐이다.

4. 고찰

  • HTN의 VAT는 3.3절에서 보정 후에도 두 코호트에서 일관된 연관을 보였지만, valid로 선택한 모델에서는 성별·나이·키·체중 위에 분류력을 더하지 못했고 선택된 VAT feature의 OR도 Sinchon에서 약해졌다. 체중·나이와 VAT가 정보를 많이 공유할 가능성이 있으나 공선성은 확인하지 않았다.
  • 후보가 333개인데 valid 양성은 2~60명이라 선택이 valid의 잡음에 흔들리기 쉽다. internal Δ는 모두 CI가 0을 포함하므로 "실제 Δ가 0에 가깝다"와 "선택 과정의 과적합"을 현재 데이터로는 구분하지 못한다.
  • 병원, 스캐너, 유병률, 성별 구성이 달라서 external 하락의 원인이 일반화 실패인지 case-mix·장비 차이인지 알 수 없다. 특히 AEC는 장비와 얽혀 있다. VAT가 SAT보다 연관이 강하다는 방향은 선행연구와 같다(부록).

5. 한계

결과를 읽을 때 가장 중요한 점은 질환 환자가 적다는 것이다.

  • 양성 수가 적다. valid·test 양성이 DM 10명·19명, CKD 2명·4명이라 선택과 평가의 분산이 크고, 결과는 단일 split(seed 111)의 값이다. 후보 333개를 valid 한 번으로 탐색했기 때문에 valid AUC는 낙관적이다.
  • 단면 자료라 발병 이전의 위험 예측이 아니라 현재 유병 상태를 분류한다. 정상군에는 미진단 환자가 섞일 수 있고, CKD 단독군은 비전형적인 소집단일 수 있다.
  • 평가 방식과 feature 정의·선택 규칙을 이전 결과를 본 뒤에 정했으므로 external은 완전한 blind가 아니다. 병원·장비·촬영 조건은 보정하지 않았다.
  • 라벨 출처와 CKD 판정 기준, CT 프로토콜, landmark 검출 방식, AEC 단위, 결측 비율, IRB는 아직 정리하지 못했고 TRIPOD+AI 항목 대조도 하지 않았다.
