# 논문 구조 정리
**"AEC-128 tube-current modulation curve as an opportunistic diagnostic biomarker" (초안)**

원본: `docs/논문 materials&methods 초안.docx`
레퍼런스 구조 대조본: `docs/논문_구조_레퍼런스_정리.md` (Chang & Yoon, Radiology 2024)

## Abstract (5단 구성)
Background → Purpose → Materials and Methods → Results → Conclusion

- **Background**: opportunistic CT 스크리닝은 이미 자리잡았지만, 스캐너의 AEC(Automatic Exposure Control) tube-current 변조곡선은 획득 메타데이터로만 취급되어 진단 바이오마커로 평가된 적이 없다는 갭 제시
- **Purpose**: AEC-128 곡선 기반 shape score가 임상/체지방 baseline 대비 당뇨·고혈압·만성신질환(CKD) 분류 성능을 개선하는지, 내부 개발 코호트와 독립 외부 검증 코호트에서 평가
- **Materials and Methods**: 두 상급종합병원 코호트(내부 1088명/외부 925명, 100kVp), FPCA로 disease-agnostic score 도출, 2개의 nested 로지스틱 회귀 모델군(clinic4+mean_mAs, clinic4+VAT+SAT), Bonferroni 보정(α=.0021, 24회 검정) 적용
- **Results**: 당뇨병은 외부 코호트에서 두 baseline 모두 Bonferroni 유의(P≤.002), CKD는 외부 코호트 한 계열에서만 유의(P<.001); 내부 코호트 당뇨 개선과 외부 고혈압 개선은 nominal 유의였으나 보정 후 탈락
- **Conclusion**: 추가 촬영·피폭 없이 이미 기록되는 신호로, 외부검증에서 통계적으로 견고한 작지만 유의한 부가가치 확인

## 1. Introduction (4개 문단)

**문단 1 — 배경**
- Opportunistic CT 스크리닝이 심대사질환 예측의 확립된 패러다임이 되었다는 도입(1-3)
- 기존 opportunistic biomarker는 전부 "재구성된 CT 영상"에서 유래 — AEC tube-current 변조곡선은 거의 주목받지 못한 신호라는 문제 제기

**문단 2 — 기전 설명 (레퍼런스의 "선행연구 나열" 대신 "왜 그럴듯한가" 논증으로 대체)**
- AEC가 환자 단면 감쇠 프로파일에 따라 실시간 조정되는 원리 설명(4,5)
- 이 곡선이 체성분(근육량/밀도, 지방량/감쇠)을 암묵적으로 인코딩할 것이라는 논리적 연결(6–8) — CT 체성분 지표가 심대사질환과 연관된다는 기존 근거(1,9)와 연결

**문단 3 — 갭**
- AEC/tube-current-modulation 관련 선행연구는 전부 방사선량 감소·추정 목적(4,5,6–8,10)일 뿐, 진단정보 여부는 검증된 적 없다는 명시적 novelty 주장

**문단 4 — 목적 (독립 문단)**
- "The aim of this study was therefore to evaluate..."로 시작, AEC-128 score를 세 질환(HTN/DM/CKD)에 대해 여러 복잡도의 모델에 추가했을 때의 개선 여부를 내부/외부 코호트에서 평가한다고 명시

→ **레퍼런스 대비 차이**: 레퍼런스는 "다른 여러 바이오마커의 선행연구 나열"형 문단2였으나, 이 초안은 단일 신규 바이오마커(AEC 곡선)의 "왜 그럴듯한가"를 논증하는 문단으로 대체 — 연구 성격(다중 바이오마커 비교 vs 단일 신규 바이오마커 제안)에 맞는 자연스러운 변형

## 2. Materials and Methods

### 2-0. 윤리 승인
- IRB 승인번호 [PLACEHOLDER] — 유일하게 남은 실질 공백

### 2-1. Patients
- 내부(Gangnam Severance)/외부(Sinchon Severance) 두 상급종합병원, 100kVp 균일, 스캐너 벤더 무필터(외부검증이 이기종 스캐너에도 적용됨을 보장)
- Inclusion/exclusion: 20세 미만 제외 + 필수 임상변수 결측 제외 → 최종 1088/925명
- Figure 1(플로우차트, 실제 이미지 삽입됨: 1090→2명 제외→1088 / 926→1명 제외→925)

### 2-2. Measurements (4개 소제목 — 레퍼런스의 3개보다 세분화)
1. **CT image acquisition** — AEC 신호의 정의(z축 방향 실시간 tube-current 조정)
2. **AEC-128 curve derivation** — series 필터링 → TotalSegmentator(11)로 liver/hip landmark 획득 → pubis–liver 구간 추출 → 128포인트로 리샘플링. Figure 2(실제 이미지 삽입: 6패널 FPCA 시각화, k=3/97.4% 분산 명시)
3. **Clinical and scan-level predictor variables** — clinic4(age/sex/height/weight), mean_mAs, VAT+SAT(비율 아닌 절대 합산값 — 명시적으로 "rather than a ratio")
4. **Outcome variables (HTN, DM, CKD)** — 이미 판정된 라벨 사용, 새로운 이분화 없음

### 2-3. Statistical Analysis
1. 기술통계 방법 명시(mean±SD/Welch's t, n(%)/chi-square) — Table 1 참조
2. FPCA로 단일 disease-agnostic score 도출, Kneedle/elbow로 k 결정(12,13,14 — FPCA 텍스트북 + 임상 적용 선례 2건), (15)Kneedle 알고리즘
3. Family A/B 2개의 3단계 nested 로지스틱 회귀 설계 설명
4. 5-fold stratified CV(내부, OOF), FPCA/스케일러 fold별 재적합(leakage 방지), 외부는 1회 고정 적용
5. Paired DeLong test(16,17)로 인접 모델 쌍 비교, Youden's J(18)로 임계값 결정
6. 스캐너 서브그룹 재계산(재학습 없이)
7. **Bonferroni 보정**: 24회 검정(3질환×2계열×4비교×2코호트), α=.0021 — 레퍼런스의 α/45, α/48 패턴과 동일한 서술 방식
8. 소프트웨어: Python(version 3.13.9)+scikit-learn/SciPy/NumPy/pandas 버전 명시 — 레퍼런스의 "Stata software (version 17.0; StataCorp)" 관례를 그대로 적용

→ **레퍼런스 대비 특징**: 레퍼런스는 Poisson/Cox regression + restricted cubic spline(유병/발생 이중 설계)이었지만, 이 초안은 nested logistic regression + paired DeLong test(단면 분류 성능 비교) 설계 — 연구 질문(횡단적 진단분류 개선 여부)에 맞는 방법론적 변형

## 4. Discussion (6개 문단 + 결론 — 레�거런스와 동일한 문단 수)

**문단 1 — 결과 요약**
- Bonferroni 통과 결과만 "improved"로, 나머지는 "nominally significant... reported as exploratory"로 명확히 구분해 과대해석 방지

**문단 2 — 당뇨병 결과 강조**
- 외부 코호트 cross-baseline 재현성을 "가장 견고한 결과"로 제시
- 내부 코호트 결과는 "supportive rather than confirmatory"로 격하, 외부 코호트의 높은 유병률이 검정력 차이의 더 parsimonious한 설명이라는 논증(기전적 차이보다 통계적 검정력 차이를 우선 고려)

**문단 3 — 선행연구와의 차별성 (레퍼런스의 "기전별 해석" 대신 "novelty framing")**
- AEC/tube-current 선행연구는 전부 방사선량 관리 목적뿐, 진단 바이오마커로 다룬 적 없다는 주장 재확인(4,5,6–8,10)

**문단 4 — 실용적 가치**
- "AEC curve is, in effect, free" — 추가 피폭·스캔시간·segmentation 없이 얻어지는 신호라는 opportunistic screening 논리(2)와 연결

**문단 5 — Limitations (First~Finally, 6개 항목)**
1. 체구 교란 가능성(단, VAT+SAT 이미 포함된 상태에서도 증분 존재한다는 반박 포함)
2. HTN/CKD가 내부에서 비유의 — 검정력 vs 코호트 특이적 효과 구분 불가
3. 두 코호트 모두 단일 의료시스템 내 상급종합병원 — 일반화 제한
4. 결과변수가 protocol-driven이 아닌 기존 임상DB 라벨
5. FPCA 성분수(k)가 사전고정 — 성능 최적화 대상 아니었음
6. Bonferroni는 non-independent nested comparison에 대해 보수적이라는 한계 + 스캐너 서브그룹 변동성(CKD, range 최대 0.29) 캐비엇

**결론 문단**
- Bonferroni 통과 결과(외부 DM/CKD)를 "통계적으로 견고"로, 내부 신호는 "directionally consistent but not significant"로 정확히 구분
- 향후 방향: 대규모 다기관 검증, 체구 보정 feature, 기전 규명

→ **레퍼런스 대비 차이**: 레퍼런스의 문단 3–5는 바이오마커별(지방→간→근육→혈관) 기전 해석이었지만, 이 초안은 단일 바이오마커라 "novelty 프레이밍(문단3) + 실용적 가치(문단4)"로 대체 — 구조적 문단 수·역할은 유사하게 유지하면서 내용은 연구 성격에 맞게 재배치
