# 1D CNN 기반 의료 데이터 연구 레퍼런스 조사 (2026-09-03)

AEC-128 곡선(z축 mA 변조 곡선, [[project_aec_signal_definition]])에 1D CNN을 적용하는 방법론적 근거를 확보하기 위해 조사. CT AEC 곡선에 1D CNN을 직접 적용한 선행연구는 확인되지 않아, 구조가 가장 유사한 "1D 시계열/생리 신호 → 1D CNN → 분류" 계열 문헌으로 대체 조사함.

---

## 1. ECG 분류 (1D CNN 원조격 응용)

### Kachuee et al., "ECG Heartbeat Classification: A Deep Transferable Representation" (IEEE ICHI 2018)
- **링크**: [arXiv](https://arxiv.org/pdf/1805.00794)
- **데이터**: MIT-BIH Arrhythmia(부정맥 5클래스) + PTB Diagnostic ECG(MI 유무), lead II만 사용, 125Hz 재샘플링 후 R-peak 기준 비트 분할·zero-padding
- **아키텍처**: 1D conv(필터 32, kernel 5) → **residual block 5개**(conv-ReLU-conv+skip+maxpool, 총 13 weight layer) → FC(32)×2 → Softmax. PCA/eigenvector 없음 — MI 예측은 마지막 conv layer의 activation을 그대로 representation으로 재사용(전이학습), 시각화만 t-SNE 사용
- **태스크/성능**: 부정맥 5클래스 분류 Acc 93.4%, MI 분류(전이학습) Acc 95.9%

### Li, Zhang, Zhang, Wei, "Classification of ECG Signals Based on 1D Convolution Neural Network" (IEEE Healthcom 2017)
- **링크**: [IEEE Xplore](https://ieeexplore.ieee.org/document/8210784/)
- **데이터**: MIT-BIH Arrhythmia, wavelet threshold denoising + wavelet 기반 R-peak 검출로 130샘플 비트 분할
- **아키텍처**: Input(130) → C1(1D conv, kernel 7, 필터 18개) → 124×18 → S1(maxpool) → 62 → C2(kernel 7, 필터 18개) → 56 → S2(maxpool) → 28 → FC → Softmax(5클래스, N/L/R/A/V). Fig. 4에 "number of eigenvectors: 18"이라는 라벨이 붙어 있으나, 본문 서술("18 feature vectors")과 대조하면 이는 **PCA 고유벡터가 아니라 각 conv layer의 출력 채널(=커널) 개수를 가리키는 용어 오용**(중국어 特征向量가 "eigenvector"·"feature vector" 양쪽으로 번역되는 데서 기인한 것으로 추정)
- **태스크/성능**: 5클래스 부정맥 분류, Acc 97.5%

---

### "ECG classification using 1-D convolutional deep residual neural network" (PLOS ONE, 2023)
- **링크**: [PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0284791) / [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC10128986/)
- **데이터**: MIT-BIH 기반 heartbeat, 클래스 불균형 문제를 SMOTE로 보정
- **아키텍처**: 1D ResNet(잔차 연결 포함 1D conv 스택), R-R-R 세그멘테이션 전략으로 원시 ECG를 비트 단위 입력으로 변환
- **태스크/성능**: 부정맥 다중분류, Acc 98.63% / Sens 92.41% / Spec 99.06% / F1 92.63%

### "Real-Time Patient-Specific ECG Classification by 1D Self-Operational Neural Networks" (arXiv, 2021)
- **링크**: [arXiv](https://arxiv.org/pdf/2110.02215)
- **데이터**: MIT-BIH, 환자별(patient-specific) 파인튜닝 세팅
- **아키텍처**: 1D CNN의 컨볼루션 연산 자체를 비선형 연산자로 대체한 Self-ONN(Operational Neural Network) — 표준 conv 대비 표현력 확장을 노림
- **태스크/성능**: 실시간 부정맥 분류, 경량화·저지연에 초점

## 2. EEG / 생리 신호 전반

### 1D-CNN 기반 뇌전증(epileptic seizure) 탐지 — UCI Epileptic Seizure Recognition 데이터셋
- **링크**: [MDPI 리뷰(Deep Convolutional Neural Networks in Medical Image Analysis: A Review)](https://www.mdpi.com/2078-2489/16/3/195)에서 인용된 사례 (원 논문 개별 URL 미확인)
- **데이터**: UCI Epileptic Seizure Recognition(단일 채널 EEG 시계열)
- **아키텍처**: 순수 1D CNN(conv-pool 스택 + FC head)
- **태스크/성능**: 발작 유무 이진분류, 정확도 최고 99%

### 1D-CNN + Stacked LSTM 하이브리드 — CHB-MIT 데이터셋
- **링크**: 위와 동일한 [MDPI 리뷰](https://www.mdpi.com/2078-2489/16/3/195)에서 인용된 사례 (원 논문 개별 URL 미확인)
- **데이터**: CHB-MIT Scalp EEG Database(다채널 장시간 EEG)
- **아키텍처**: 1D CNN으로 국소 파형 특징 추출 → Stacked LSTM으로 시간적 의존성 학습(CNN-LSTM 직렬 결합)
- **태스크/성능**: 발작 자동 탐지, 정확도 90%

### "Deep Learning in Physiological Signal Data: A Survey" (Sensors, 2020)
- **링크**: [MDPI](https://mdpi.com/1424-8220/20/4/969/htm) / [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC7071412/)
- **데이터**: EMG/ECG/EEG/EOG 등 다종 생리 신호를 다룬 논문 147편 리뷰(개별 원저 아님)
- **아키텍처**: 1D CNN, RNN/LSTM, CNN-RNN 하이브리드 등 신호별 적용 사례를 종합
- **핵심 주장**: 1D CNN은 시계열 원시 데이터에서 별도의 시간/자원 소모적 feature engineering 없이 SOTA급 성능을 낼 수 있다는 것이 CNN 채택의 핵심 근거

### "Recognizing diseases with multivariate physiological signals by a DeepCNN-LSTM network" (Applied Intelligence, 2021)
- **링크**: [Springer](https://link.springer.com/article/10.1007/s10489-021-02309-2)
- **데이터**: 다변량(multivariate) 생리 신호(여러 채널의 시계열 동시 입력)
- **아키텍처**: DeepCNN으로 각 채널의 지역적 특징 자동 추출 → LSTM으로 채널 간·시점 간 시간적 의존성 통합(CNN-LSTM 결합)
- **태스크**: 다변량 신호 기반 질병 인식(disease recognition)

## 3. 딥러닝 vs 비딥러닝 비교 (반박형, Discussion 인용 가치)

### "Does Deep Learning REALLY Outperform Non-deep Machine Learning for Clinical Prediction on Physiological Time Series?" (arXiv, 2022)
- **링크**: [arXiv](https://arxiv.org/pdf/2211.06034)
- **데이터**: 임상 생리 시계열(다기관 벤치마크)
- **아키텍처**: 1D CNN·RNN 계열 딥러닝 모델과 전통 ML(트리 기반 등)을 동일 조건에서 비교
- **핵심 주장**: 생리 시계열 임상 예측에서 딥러닝이 항상 비딥러닝보다 우수하지 않음 — [[project_step6_deep_learning_reimplementation]]에서 CNN이 clinic4 대비 목표(+0.05~0.1 AUC) 미달(Δ-0.0004)한 것과 같은 방향의 결론이라 Discussion 반박 근거로 인용 가치 있음

## 결론

- CT AEC 곡선처럼 "1D 변조 곡선 + 소수 정형변수 → 이진 예측"이라는 문제 형태에 직접 대응하는 선행연구는 없음(가장 근접한 선례는 [[project_step6_multimodal_fusion_references]]에 정리된 DeepSpiro).
- 위 ECG/EEG 문헌들은 "원시 1D 시계열에 conv 스택을 직접 적용해 자동 feature extraction이 가능하다"는 방법론적 정당화(Method justification)로만 인용 가능하며, 성능 수치(97~99%)를 AEC-128 CNN 결과와 직접 비교할 근거는 아님 — ECG/EEG는 신호 자체에 병리적 파형 패턴이 존재하는 반면, AEC-128은 [[project_aec_curve_zero_ablation_no_signal]]·[[project_aec_10day_architecture_rotation_result]] 등 19~20가지 독립 방법론에서 곡선 고유 신호가 확인되지 않은 상태.
